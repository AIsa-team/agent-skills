# aisa

Canonical AIsa Skill. Agents: follow [SKILL.md](./SKILL.md). Humans: [Agent Skills Quickstart](https://aisa.one/docs/agent-skills/quickstart).

Reuse a working connection or an explicit transport choice first. Default to MCP at `https://tools.aisa.one/mcp` wherever the client can add the connector — user-local or cloud. Use the CLI only without an MCP mechanism, for non-interactive automation with an existing key, or by explicit choice; Node must already be installed.
