# Changelog

## 1.1.0

- Default new projects to host-managed AIsa MCP. Support the official AIsa CLI as a selected alternative and keep direct API adapters behind explicit REST compatibility mode. An environment key never selects the transport automatically.
- Build native generation requests from discovered tools, complete JSON Schemas and model-specific contracts, without a model allowlist. Bind model options, product references, prompts and response mappings to the approved playbook.
- Preserve exact request/quote/session evidence, settled charges and asynchronous task IDs through preparation, dispatch, result ingestion, review and export. Resume known jobs without submitting replacements or switching transports.
- Preserve legacy project approvals and REST recovery, require real product photographs, and retain research, user approval and artifact review gates.
- Add native workflow and connection regression tests. Free live MCP discovery verifies exposed image/video contracts; automated generation tests use fixtures and do not claim live model quality or paid execution coverage.
