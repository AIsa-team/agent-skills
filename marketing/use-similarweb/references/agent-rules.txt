# AIsa Similarweb — compact agent protocol
Detailed discovery: references/discovery.md. Detailed billing and retry semantics: references/cost-control.md.
Requires Python 3.11+ and AISA_API_KEY with access to the requested route; never expose the key.
1. Read the live contract: https://aisa.one/docs/openapi/similarweb.json. Discover routes and inspect parameters, examples, x-aisa-constraints, and response declarations; do not assume a route count or parameter set.
2. Preserve user dates. The window command gives the previous complete UTC month only as candidate_month, with latest_month:null and availability:unverified; it does not probe a paid endpoint.
3. Build the smallest request that answers the question. Run local checks, then quote the exact request with X-AISA-Cost-Mode:quote. Checks and quotes do not prove provider data availability.
4. Compare quotes before widening scope. Honor existing user authorization and budget; resolve only missing or exceeded authorization before execution.
5. Execute with --max-usd. X-AISA-Max-Price-USD is an admission estimate threshold, not a final-charge cap. Read may_exceed_estimate; never promise a hard spending ceiling from this header.
6. For a task budget, set --task-budget-usd USD when creating --task-ledger FILE, then reuse that file. The ledger counts recorded actual charges and blocks further spending after unresolved or unknown charges; it cannot cap final charges.
7. Keep the persisted request_record and idempotency_key. Never automatically retry a paid call or replace its key to bypass an uncertain outcome. Establish the prior outcome before a deliberate retry.
8. Report the response's actual data period and cost header. Missing cost means unknown. Do not declare an error uncharged solely from its HTTP status.
9. usage reports aggregate API-key totals, not this task's individual charges. Use request-specific Usage & Logs evidence with reconcile REQUEST_RECORD --charged-usd USD --evidence TEXT to record a resolved charge locally; this command makes no API call.
Pricing semantics: https://aisa.one/docs/guides/pricing.
